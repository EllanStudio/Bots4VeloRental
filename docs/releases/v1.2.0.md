# Bots4VeloRental v1.2.0

Final release for the Issue #3 AuthMe/VeloAuth rental-BOT fix.  This release
is built against the immutable Bots4Velo Addon API `v3.0.8`, which keeps one
login/register command selection per connection, ignores conflicting prompts,
and only permits rental server switching after confirmed authentication.

The addon continues to require the core's positive `AUTHENTICATED` state; it
does not treat PLAY or a submitted command as authentication.  Jail BOT paths
and the rental database schema are unchanged.

## Verification

```bash
./gradlew clean check shadowJar -PpluginVersion=1.2.0
```

This is the final `v1.2.0` line for this fix.  No further feature iteration is
planned after this release.
