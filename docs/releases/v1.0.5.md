# Bots4VeloRental v1.0.5

The addon now recovers confirmed AuthMe/VeloAuth state when it is reloaded
after the core has already emitted `AUTHENTICATED`.  It seeds its connection-
local evidence from the new `AddonBotSnapshot.authenticationComplete` bit and
continues to require positive authentication evidence before a server switch.

This closes the listener-registration race without treating `PLAY` or a
submitted command as authentication.

## Compatibility

- Built against Bots4Velo addon API `3.0.5`.
- The on-disk `rentals.db` schema and refund state are unchanged.

## Verification

```text
./gradlew clean check shadowJar -PpluginVersion=1.0.5
```
